# DjManmeet

DJ artist portfolio and marketing website.

## Live demo (GitHub Pages)

The client-ready site lives in the **`docs/`** folder.

| What | Where |
|------|--------|
| Website files | [`docs/`](docs/) |
| Deploy instructions | [`docs/README.md`](docs/README.md) |
| Development / full template | [`UI/`](UI/) |

After enabling GitHub Pages with source **Branch: main** and folder **`/docs`**, the live URL will be:

**https://&lt;your-username&gt;.github.io/DjManmeet/**

## Repository layout

- **`docs/`** — Static site for GitHub Pages (use this for the live client demo).
- **`UI/`** — Full template workspace (includes optional PHP mail handler, vendor libs, and extra demo pages).
